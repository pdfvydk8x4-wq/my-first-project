# my-first-project — RSI-бот для Binance Spot

Простой торговый бот на Python: покупает, когда RSI(14) < 30, и продаёт, когда RSI > 70.
Держит не больше одной позиции, на каждую сделку тратит фиксированную сумму в USDT.

## ⚠️ Риски
- Торговля криптовалютой может привести к **потере всех вложенных средств**.
- Простая RSI-стратегия **не гарантирует прибыль** и часто убыточна на трендовом рынке.
- Это учебный проект, а не финансовый совет. Начинайте с **Testnet** и `DRY_RUN=true`.
- Никогда не публикуйте файл `.env` и не давайте API-ключам права на вывод средств.

## Установка
Бот не использует python-binance и pycryptodome: запросы к Binance делает маленький клиент
`bot/binance_client.py` на стандартной библиотеке Python (urllib, hmac). Поэтому он работает в a-Shell на iPhone.

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt          # только python-dotenv (необязательно)
cp .env.example .env           # затем впишите свои ключи в .env
```

## Ключи Binance Testnet
1. Откройте https://testnet.binance.vision/ и войдите через GitHub.
2. Нажмите **Generate HMAC_SHA256 Key**, задайте имя.
3. Скопируйте API Key и Secret Key в `.env` (`BINANCE_API_KEY`, `BINANCE_API_SECRET`).
4. Оставьте `USE_TESTNET=true`. На тестовом счёте уже есть виртуальные средства.

## Настройки (`.env`)
| Переменная | По умолчанию | Описание |
|---|---|---|
| `USE_TESTNET` | `true` | Тестовая сеть Binance |
| `DRY_RUN` | `true` | Только логировать сигналы, без ордеров |
| `SYMBOL` | `BTCUSDT` | Торговая пара |
| `INTERVAL` | `15m` | Таймфрейм свечей |
| `RSI_PERIOD` | `14` | Период RSI |
| `RSI_BUY` / `RSI_SELL` | `30` / `70` | Пороги покупки и продажи |
| `QUOTE_AMOUNT` | `20` | Сумма покупки в USDT |
| `POLL_SECONDS` | `60` | Пауза между проверками |

## Запуск
```bash
python main.py
```
Логи пишутся в консоль и в `bot.log`, состояние позиции в `state.json`.
Остановка: `Ctrl+C`. Чтобы ставить реальные ордера на Testnet, задайте `DRY_RUN=false`.

## Тесты
```bash
pip install -r requirements-dev.txt
pytest -v
```
Тесты проверяют расчёт RSI и логику сигналов с имитацией биржи, без сети и ключей.

## Веб-панель (дашборд)
Бот сам запускает встроенную веб-панель (только стандартная библиотека Python, без Flask) на
**http://localhost:8000**. Порт меняется через `DASHBOARD_PORT`, отключить панель можно `DASHBOARD_ENABLED=false`.

На панели: большой статус «В РЫНКЕ» / «В ОЖИДАНИИ» / «ПРОДАЁТ» / «ОСТАНОВЛЕН», флаги Testnet и DRY_RUN, пара,
текущая цена, крупные карточки RSI 6 / 12 / 24 со шкалой 0–100 (RSI 14 стратегии — под ценой), текущий сигнал
(купить / продать / держать), открытая позиция, последние 10 сделок (включая сделки в DRY_RUN),
последние 20 строк журнала и время обновления. Данные обновляются каждые ~5 секунд.

Красная кнопка **«Остановить бота»** корректно останавливает торговый цикл и завершает программу.

### Запуск на iPhone (a-Shell)
```bash
pip install -r my-first-project-main/requirements.txt
python my-first-project-main/main.py
```
Затем откройте **http://localhost:8000** в Safari на этом же телефоне.

> iOS может приостановить a-Shell в фоне, и бот перестанет работать. Отдельной команды
> «не засыпать» в a-Shell нет. Держите a-Shell на экране (например, в Split View рядом с Safari на iPad
> или переключайтесь обратно на a-Shell), а в «Настройки → Экран и яркость → Автоблокировка»
> выберите «Никогда», чтобы телефон не блокировался. Начиная с iOS 26 a-Shell сам не даёт экрану
> гаснуть, пока работает долгая команда.

Файл `.env` ищется в текущей папке, поэтому либо запускайте из папки проекта
(`cd my-first-project-main && python main.py`), либо положите `.env` туда, откуда запускаете.
